# 平台内存映射和中断分配模板

> 本文件定义平台相关的内存映射、中断分配和时钟树配置。
> 填写时将具体芯片的值替换。
> 只包含 AI 无法从代码推断的隐性知识。

## 1. 系统内存映射

| 基地址 | 大小 | 区域 | 说明 |
|--------|------|------|------|
| 0x0000_0000 | — | Boot ROM | 启动 ROM，只读 |
| 0x1000_0000 | — | SRAM | 片上 SRAM，固件运行区域 |
| 0x2000_0000 | — | DRAM | 外部 DDR，数据缓冲区 |
| 0x5000_0000 | — | NAND Controller | NAND 控制器寄存器 |
| 0x5001_0000 | — | NVMe Controller | NVMe 控制器寄存器 |
| 0x5002_0000 | — | DMA Controller | DMA 控制器寄存器 |
| 0x6000_0000 | — | GIC Distributor | 中断控制器分配器 |
| 0x6001_0000 | — | GIC CPU Interface | 中断控制器 CPU 接口 |

> **规则**：以上地址必须与链接脚本（.ld）中的 REGION 定义完全一致。

## 2. 中断分配

| 中断号 | 名称 | 优先级 | 说明 |
|--------|------|--------|------|
| 32 | NAND_CMD_COMPLETE | 高 | NAND 命令完成 |
| 33 | NAND_DMA_COMPLETE | 高 | NAND DMA 传输完成 |
| 34 | NAND_ECC_ERROR | 高 | NAND 不可纠正 ECC 错误 |
| 64 | NVME_SQ0 | 最高 | Admin 提交队列门铃 |
| 65 | NVME_SQ1 | 高 | I/O 提交队列 1 门铃 |
| 66 | NVME_SQ2 | 高 | I/O 提交队列 2 门铃 |
| 67 | NVME_CQ0 | 最高 | Admin 完成队列中断 |
| 68 | NVME_CQ1 | 高 | I/O 完成队列 1 中断 |
| 69 | NVME_CQ2 | 高 | I/O 完成队列 2 中断 |
| 128 | TIMER_0 | 中 | 定时器 0（看门狗） |
| 129 | TIMER_1 | 中 | 定时器 1（GC 调度） |

> **规则**：
> - 高优先级中断（NAND、NVMe）必须优先于中优先级（定时器）。
> - ISR 中禁止嵌套同优先级中断。
> - 中断处理函数中只做标志设置和任务通知，不做数据处理。

## 3. 时钟树配置

| 时钟域 | 源时钟 | 分频 | 目标频率 | 说明 |
|--------|--------|------|----------|------|
| CPU_CLK | PLL0 | 1 | 800 MHz | CPU 核心时钟 |
| NAND_CLK | PLL1 | 4 | 200 MHz | NAND 控制器时钟 |
| NVME_CLK | PLL1 | 2 | 400 MHz | NVMe 控制器时钟 |
| DMA_CLK | PLL1 | 4 | 200 MHz | DMA 引擎时钟 |
| AHB_CLK | PLL0 | 4 | 200 MHz | AHB 总线时钟 |
| APB_CLK | PLL0 | 8 | 100 MHz | APB 总线时钟 |

> **配置顺序约束**：
> 1. 先配置 PLL（锁相环），等待 LOCK 位。
> 2. 再配置分频器。
> 3. 最后切换时钟源到 PLL 输出。
> 4. 禁止在运行时切换 NAND/NVMe 时钟源。

## 4. 填写说明

1. 将基地址、中断号、时钟频率替换为**实际芯片的值**。
2. 中断优先级和 ISR 约束必须与 RTOS 优先级配置一致。
3. 时钟配置顺序约束不可打乱。
4. 每个不同芯片平台一个文件，命名格式：`memory_map_<platform>.md`。
