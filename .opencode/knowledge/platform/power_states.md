# 电源状态转换模板

> 本文件定义 SSD 固件的电源状态转换约束和规则。
> 填写时将具体芯片的值和平台策略替换。

## 1. NVMe 电源状态

| 电源状态 | 名称 | 描述 | 延迟 | 功耗 |
|----------|------|------|------|------|
| PS0 | 活跃最高性能 | 全速运行 | 0 | 最高 |
| PS1 | 活跃中等性能 | 降频运行 | < 1ms | 中等 |
| PS2 | 活跃低性能 | 最低运行频率 | < 1ms | 较低 |
| PS3 | 非活跃空闲 | 空闲省电 | < 50ms | 低 |
| PS4 | 非活跃深度省电 | 深度睡眠 | < 500ms | 很低 |

> 以上状态为 NVMe 定义的典型状态，实际数量和参数取决于控制器规格。

## 2. 状态转换规则

### 2.1 转换矩阵

| 从\到 | PS0 | PS1 | PS2 | PS3 | PS4 |
|-------|-----|-----|-----|-----|-----|
| PS0 | — | ✅ | ✅ | ✅ | ✅ |
| PS1 | ✅ | — | ✅ | ✅ | ✅ |
| PS2 | ✅ | ✅ | — | ✅ | ✅ |
| PS3 | ✅ | ✅ | ✅ | — | ✅ |
| PS4 | ✅ | ✅ | ✅ | ✅ | — |

> PS4 → PS0 的恢复时间最长，必须确保所有硬件模块重新初始化。

### 2.2 转换顺序约束

**进入省电状态（PS0 → PS3/PS4）的顺序：**

1. 暂停所有 I/O 队列处理
2. 等待所有未完成的 NAND 操作完成
3.刷写 DRAM 缓冲区到 NAND
4. 禁用中断（保留唤醒中断）
5. 配置控制器进入低功耗模式
6. 关闭 NAND 通道时钟
7. 关闭不必要的 PLL

**恢复到全速状态（PS3/PS4 → PS0）的顺序：**

1. 使能 PLL，等待锁定
2. 使能 NAND 通道时钟，等待稳定
3. 重新初始化 NAND 控制器
4. 恢复中断配置
5. 重新使能 I/O 队列处理
6. 报告主机电源状态恢复

> **规则**：PS4 → PS0 必须按上述顺序逐步恢复，不可跳步。

## 3. 硬件约束

### 3.1 时钟恢复

| 组件 | 关闭顺序 | 恢复时间 | 恢复约束 |
|------|----------|----------|----------|
| PLL1 | 先关外设再关 PLL | 50-200 µs | 必须等 LOCK 位 |
| NAND 时钟 | 关 PLL 前先关 | < 1 µs | 无特殊约束 |
| CPU 时钟 | 最后关 | 0 | 从 WFI/WFE 恢复 |

### 3.2 DRAM 刷新

- 省电状态必须保持 DRAM 自刷新模式。
- 进入自刷新前必须等待 DRAM 控制器 idle。
- 退出自刷新后必须等待 DRAM 控制器就绪。
- **禁止在 DRAM 自刷新状态下访问 DRAM。**

### 3.3 NAND 保存

- 进入 PS3/PS4 前必须确保所有 DRAM 脏数据已刷写到 NAND。
-映射表必须保存到 NAND 专用区域。
- 坏块表必须保存到 NAND 专用区域。
- 恢复时必须先加载映射表和坏块表。

## 4. 异常处理

| 异常 | 处理 | 恢复 |
|------|------|------|
| 恢复超时 | 重试恢复序列 | 最多 3 次，仍失败则报告致命错误 |
| DRAM 自刷新失败 | 报告错误 | 无法恢复，需重启 |
| NAND 保存失败 | 重试保存 | 最多 3 次，仍失败则强制断电 |
| 意外唤醒 | 检查唤醒源 | 按正常恢复流程处理 |
