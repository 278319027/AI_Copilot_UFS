# NAND 时序和并发约束模板

> 本文件定义 NAND 操作的并发约束和时序安全规则。
> AI 生成相关代码时必须遵守这些约束。

## 1. 操作互斥约束

以下操作对**不可同时执行**于同一个 Die：

| 操作 A | 操作 B | 原因 |
|--------|--------|------|
| Page Program | Page Read | 同一 Die 不可同时读写 |
| Block Erase | 任何操作 | 擦除期间该 Die 不可响应其他命令 |
| Page Program | Page Program | 同一 Die 不可同时编程（不同 Die 可并行） |

以下操作对**可以并行**：

| 操作 A | 操作 B | 条件 |
|--------|--------|------|
| Channel 0 读取 | Channel 1 读取 | 不同通道 |
| Die 0 编程 | Die 1 读取 | 同一通道不同 Die（需检查控制器规格） |
| DMA 传输 | NAND 操作 | 不同通道 |

## 2. 时序安全约束

### 2.1 必须等待的操作

| 操作后 | 等待条件 | 超时值 |
|--------|----------|--------|
| 发起页读取 | NAND_INT_STAT.RDY_INT == 1 | 50 µs |
| 发起页编程 | NAND_INT_STAT.RDY_INT == 1 | 1 ms |
| 发起块擦除 | NAND_INT_STAT.RDY_INT == 1 | 15 ms |
| 软复位 | NAND_STATUS.READY == 1 | 1 ms |

> **规则**：禁止无超时的忙等循环。每次等待必须有合理的超时值和超时处理。

### 2.2 配置顺序约束

> 以下顺序不可打乱：

1. 时钟使能 → 等待时钟稳定 → 配置时序 → 配置 ECC → 配置 DMA → 使能中断 → 发起操作
2. 读操作：发命令 → 发地址 → 等待就绪 → 读数据
3. 写操作：发命令 → 发地址 → 写数据 → 发命令结束 → 等待就绪 → 检查状态

## 3. 缓冲区安全约束

- NAND 读取 DMA 缓冲区必须 cache line 对齐（≥ 32 字节）。
- DMA 传输前必须 flush cache（源地址方向）。
- DMA 传输后必须 invalidate cache（目标地址方向）。
- NAND 操作期间禁止 CPU 修改同一缓冲区。
- 连续操作之间必须有适当的缓冲区同步屏障。

## 4. 错误恢复约束

- 操作失败后，必须先读取状态寄存器确认失败原因。
- 重试最多 3 次，每次重试前必须等待就绪。
- 3 次重试后仍失败，标记坏块并报告上层。
- 超时后必须软复位控制器，恢复到已知状态。
- 软复位后必须重新配置控制器参数。
