### 10.4 CodeGraph 查询命令

```bash
# 查询此模块的调用者
codegraph callers <module_entry_function>

# 查询此模块的依赖
codegraph deps source/<module_dir>

# 查询修改影响
codegraph impact source/<module_dir>/<file>.c

# 补充查询（函数指针和宏）
cscope -d -L2 "<function_ptr_name>"
```
